# 文件整理小工具

用 Python 写的小脚本，帮你批量重命名文件，并按后缀自动分类到对应文件夹。

## 功能
- `rename.py`：批量重命名，例如改成 001.txt、002.txt……
- `sort.py`：按文件后缀（pdf、docx、jpg 等）自动建文件夹并分类
- `undo.py`：把整理后的文件移回原位置（反向操作）

## 使用方法
1. 安装 Python 3
2. 打开脚本，把 `folder` 改成要整理的文件夹路径
3. 先把 `preview = True`，运行预演，确认结果没问题
4. 再改成 `preview = False`，真正执行

## 注意
- 脚本会真正移动文件，使用前请先备份重要文件
- 只处理文件，不会动已有的文件夹
